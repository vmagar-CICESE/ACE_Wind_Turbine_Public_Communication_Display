## ⚠️ Correction
`ace-turbine-community-event-2023.webp` (kept here for reference only — **do not use it as a
turbine photo**) was found on the ACE homepage news post about the "Running Out of Time
Climate Baton" relay (4 July 2023). On closer inspection it actually shows a surfer at
**The Wave, Bristol** — the relay's starting point *before* the baton reached the turbine —
not the ACE turbine itself. It was mistakenly used as a turbine photo in an early draft of
Concept 2 and has since been replaced there with an SVG illustration. Left in this folder
purely so the mistake isn't repeated.

## Why there are so few official photos
The ACE (ambitioncommunityenergy.org) and ALW (ambitionlw.org) websites are simple
WordPress sites with no media/photo gallery page — this is the only turbine photo found
on them. Other options to consider:
- Ask ACE/Charlie Plumley directly for a press photo (safest, clearly licensed option).
- Use a simple icon/illustration of a wind turbine instead of a real photo — this is what
  the existing "ACE Wind Now" gallery entry does (see
  [../challenge-repo-guides/existing-creations-gallery.json](../challenge-repo-guides/existing-creations-gallery.json)).
- Use the turbine's location from the Zenodo KMZ file to show a map pin instead of a photo
  (Google Earth / Google Maps / Leaflet.js can open a `.kmz` or its coordinates directly).
  Source: https://doi.org/10.5281/zenodo.22662372
- Take a screenshot of the existing live dashboard (https://ace-api.duckdns.org/dashboard/)
  for moodboard/reference purposes only (not for the final public display).
